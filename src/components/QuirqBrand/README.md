# QuirqBrand

`QuirqMark` (the "q" tile) and `QuirqWordmark` (lowercase "quirq", drawn in `currentColor`) as inline SVG.

The source assets live in [quirq-ai/innernet](https://github.com/quirq-ai/innernet) under `public/brand/quirq/`. The favicon and logo in `static/quirq-icon.svg` is the same tile. The desktop wallpapers in `static/brand/quirq/` (`mobius.jpg`, `og.jpg`) come from the same folder.

Write the name in lowercase: **quirq**.
